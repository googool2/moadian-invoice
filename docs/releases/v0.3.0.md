Build, validate, explain and safely send Iranian Moadian (سامانه مودیان) e-invoices with Claude, without guessing.

## Install

Claude Code plugin:

```
/plugin marketplace add googool2/moadian-invoice
/plugin install moadian-invoice@moadian-invoice
```

**claude.ai:** upload both zips attached below under Settings › Capabilities › Skills.

**Requirements:** Python 3.10+. `pip install moadian-full` is needed only for building and sending.

## What's in 0.3.0

- **Error codes checked against the official lists.** Every code was compared with:
  - RC_TXPS.EC_V02, «کد خطاهای سامانه مودیان», اسفند ۱۴۰۲;
  - RC_TXPS.RE_V01, «خطاهای پرتکرار», دی ۱۴۰۲.

  Each row now says whether the official text confirms it. The code scheme, the field numbers and all API and transport codes come from EC_V02.
- **More codes:** every API and transport code in EC_V02, with its official message. This includes the old v1 API and five transport codes that were missing.
- **Short codes:** `explain_error.py` understands the short forms used in RE_V01 and on vendor pages. For example, `0301` maps to `0300101` and `0344` to `0304401`.
- **Fix: export VAT.** The error reference said export lines need a non-zero VAT rate. That came from a secondary summary of the older RE_V01. EC_V02 and the newer guideline V7.8 §7-41 both say `vra = 0` on export, which is what the validator already checked.
- **V7.9 fields:** `insr` (value 1 for an Article 9 invoice sent late) and `nti1`/`nti2` (notes, up to 30 characters) now cite a page-referenced transcription of V7.9.

## Measured

- **Validator benchmark:** unchanged at 13/13 valid invoices left clean and 37/37 seeded defects caught at the root. The validator itself did not change.
- **CI:** Ubuntu, macOS and Windows × Python 3.10 and 3.13.

## Honest note

- **V7.9:** the PDF itself could not be reached from the build environment. `insr`, `nti1` and `nti2` stay `[UNVERIFIED]`.
- **Codes seen only in real replies:** a few, such as `00107`, still rest on secondary sources.
- **Real-world testing:** the send path has only been tested against a fake server. No real taxpayer invoices have been tested yet.
- **Not tax advice.**
