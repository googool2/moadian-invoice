Build, validate, explain and safely send Iranian Moadian (سامانه مودیان) e-invoices with Claude, without guessing.

## Install

Claude Code plugin:

```
/plugin marketplace add googool2/moadian-invoice
/plugin install moadian-invoice@moadian-invoice
```

**claude.ai:** upload both zips attached below under Settings › Capabilities › Skills.

**Requirements:** Python 3.10+. `pip install moadian-full` is needed only for building and sending.

## What's in 0.2.0

- **Two skills in one plugin:**
  - `moadian-invoice` builds, validates and explains, fully offline.
  - `moadian-send` is the only part that touches the network.
- **Two-step sending:**
  - An offline `prepare` step prints a confirmation code bound to the exact file and target.
  - Keys come only from environment variables.
  - Live sending needs `MOADIAN_ALLOW_LIVE=1`, set by you.
  - Invoices older than a week and already-sent taxids are blocked.
- **Fixes for moadian-full's send path:** stale `sigT`, a server key cached across sandbox and live, hard-coded URLs, and no support for encrypted keys.
- **Check-digit warnings** for national codes and legal-entity ids.
- **Fixes:**
  - a validator crash on export invoices;
  - a crash on Windows when output is piped;
  - an old invoice date going unflagged in the build report.

## Measured

- **Scenario eval: assertions passed 96% with the skill, 51% without** (5 scenarios × 3 isolated headless runs each, graded independently).
  - The skill costs more: median $0.142 against $0.097 per run.
  - It is faster: 20 s against 25 s.
- **Trigger evals:** 20/20 for `moadian-invoice` and 6/6 for `moadian-send`.
- **Validator benchmark:** 13/13 valid invoices left clean and 37/37 seeded defects caught at the root. Version 0.1.0 scored 12/13 and 33/37.
- **CI:** Ubuntu, macOS and Windows × Python 3.10 and 3.13.

## Honest note

- **Real-world testing:** the send path has only been tested against a fake server, never against the real sandbox or the live system. No real taxpayer invoices have been tested yet.
- **Error codes:** meanings come from secondary sources.
- **Not re-measured:** the date-warning fix was made after the scenario runs.
- **Not tax advice.**
